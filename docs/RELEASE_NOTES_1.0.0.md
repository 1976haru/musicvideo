# MV Director Studio 1.0.0 Release Notes

MV Director Studio 1.0은 음악과 가사에서 시작해 World, Story, Shot, manual generation pack, Take/QC, Rough Cut과 최종 MP4까지 연결하는 Windows desktop workflow입니다.

Windows ONEDIR 실행본, 앱 로컬 FFmpeg 탐지, 첫 실행 환경 점검, session backup/crash recovery, rotating logs, 안전한 cache 정리, project integrity 검사와 release E2E 검증이 포함됩니다.

Provider API, 자동 브라우저 조작, 자동 생성/결제는 포함하지 않습니다.
