# MV Director Studio 1.0.3

## Complete World Bible Draft

1.0.3 upgrades World Bible promotion from a partial field copy to a complete, evidence-based production draft.

- Uses the selected WorldConcept.
- Uses lyric anchors for place, weather, object, time, color/light and nature.
- Uses the lyric emotional arc.

- Populates all 12 editable production fields: Premise, Emotional thesis, Reality rules, Time period, Visual language, Palette, Materials, Weather rules, Lighting rules, Camera rules, Recurring motifs and Forbidden elements.
- Preserves lyric foundation Line IDs.
- Regeneration asks before replacing manually edited World Bible content.
- Existing Session schema remains 1.0 and older 1.0 sessions remain compatible.
- Single-root executable deployment remains unchanged: D:\03 musicvideo\MV Director Studio.exe.
