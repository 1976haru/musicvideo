MV Director Studio 1.1.0 — 처음 시작

1. D:\03 musicvideo\MV Director Studio.exe를 실행합니다.
2. 첫 실행 진단에서 필수 도구 상태를 확인합니다.
3. 5부작이면 SERIES STUDIO에서 Series/Character/Asset을 먼저 확인합니다.
4. MUSIC → LYRICS → WORLD → REFERENCES → STORY → SHOTS → GENERATE → RESULTS → QC → EDIT/RENDER 순서로 진행합니다.
5. 중간중간 PRODUCTION CONTROL의 "전체 준비 상태 검사"를 눌러 빨간 blocker부터 해결합니다.
6. World/Character/Reference를 수정했다면 오래된 Prompt Pack이 자동으로 stale 표시됩니다. Generate에서 다시 만드세요.
7. 외부 사이트를 사용하면 MANUAL, 로컬 ComfyUI를 직접 설치해 실행했다면 COMFYUI_LOCAL을 선택할 수 있습니다.
8. Final MP4 생성 후 PRODUCTION CONTROL → 최종 영상 검증을 실행합니다.
9. 프로젝트는 세션 저장으로 선택한 JSON에 저장합니다. Queue 상태도 세션에 포함됩니다.
10. 원곡, Take, Reference, Series Asset은 프로그램이 삭제하거나 이동하지 않습니다.

문제가 생기면 "제작 준비 / 진단"에서 복구본, cache, 로그/진단 보고서를 확인하세요.
