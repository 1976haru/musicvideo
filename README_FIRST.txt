MV Director Studio 1.0.3 — 처음 시작

1. MV Director Studio.exe를 실행합니다.
2. "뮤직비디오 제작 준비가 되었나요?"에서 필수 항목을 확인합니다.
3. MUSIC → WORLD → REFERENCES → STORY → SHOTS → GENERATE → RESULTS → QC → EDIT/RENDER 순서로 진행합니다.
4. 프로젝트는 "세션 저장"으로 사용자가 선택한 JSON에 저장됩니다.
5. 원곡, Take, Reference는 프로그램이 삭제하거나 이동하지 않습니다.
6. 문제가 생기면 "제작 준비 / 진단"에서 복구본, 캐시, 진단 보고서를 확인합니다.

FFmpeg가 포함되지 않았다면 tools/ffmpeg/bin에 ffmpeg.exe와 ffprobe.exe를 넣거나 시스템 PATH에 설치하세요.
선택 AI 기능은 없어도 기본 제작과 Final Render를 사용할 수 있습니다.
